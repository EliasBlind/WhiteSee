## 1. Назначение и описание плагина

**Whitespace Language Support** — расширение для Visual Studio Code, предназначенное для удобного чтения и анализа программ на языке Whitespace.

В этом языке команды записываются с помощью пробелов, табуляций и переводов строк, поэтому обычный исходный код трудно читать. Плагин помогает разобраться в программе и понять, какие команды в ней используются.

Основные возможности расширения:

- Подсветка пробелов, табуляций и переводов строк разными цветами
- Отображение названий команд, например `push`, `add`, `jmp` и `printn`.
- Показ описания команды при наведении курсора.
- Распознавание числовых аргументов и меток.
- Выделение неизвестных команд и некоторых ошибок.
- Преобразование исходного кода в читаемый текстовый формат.
- Включение и отключение отображения мнемоник.

## 3. Архитектура и структуры данных

### Архитектура работы плагина

Плагин анализирует исходный код на языке Whitespace и помогает сделать его более понятным для пользователя.

При открытии или изменении файла расширение распознаёт команды, выделяет пробелы, табуляции и переводы строк разными цветами, а также показывает названия команд и их описание.

Если нужно посмотреть программу в более привычном виде, пользователь может воспользоваться командой дизассемблирования. После этого расширение откроет отдельную вкладку с текстовым представлением команд.

Основная логика работы реализована в файле `extension.js`, а настройки и команды расширения задаются в `package.json`.

### Структура данных `OPS`

В объекте `OPS` хранится список команд языка Whitespace. Для каждой команды указаны её код, название, тип аргумента, если он требуется, и описание.

Пример:

```javascript
const OPS = {
    SS:   { n: 'push', a: 'num', d: 'Stack: положить число в стек' },
    SLS:  { n: 'dup', d: 'Stack: дублировать верх стека' },
    SLT:  { n: 'swap', d: 'Stack: поменять местами два верхних' },

    TSSS: { n: 'add', d: 'Arithmetic: a + b' },
    TSST: { n: 'sub', d: 'Arithmetic: a - b' },

    LSS:  { n: 'label', a: 'lbl', d: 'Flow: метка' },
    LSL:  { n: 'jmp', a: 'lbl', d: 'Flow: безусловный переход' },

    LLL:  { n: 'end', d: 'Flow: конец программы' }
};
```

Здесь:

- `S` — пробел (Space).
- `T` — табуляция (Tab).
- `L` — перевод строки (Line Feed).
- `n` — название команды.
- `a` — тип аргумента: число (`num`) или метка (`lbl`).
- `d` — описание команды.

### Функция `parse(text)`

Функция `parse()` отвечает за разбор исходного кода. Она находит команды, определяет их аргументы и формирует список инструкций.

Если встречается неизвестная команда, пустое число или отсутствует завершающий перевод строки у аргумента, расширение помечает такую инструкцию как ошибочную.

Для работы с числовыми аргументами используется `BigInt`, позволяющий обрабатывать большие целые числа.

### Цветовая подсветка

Для удобства чтения элементы кода выделяются разными цветами:

- **Голубой** — пробелы в командах.
- **Оранжевый** — табуляции в командах.
- **Зелёный маркер `↵`** — переводы строк.
- **Приглушённые цвета** — аргументы команд.
- **Красный** — ошибки разбора.

Подсветка реализована с помощью возможностей VS Code API.

### Отображение мнемоник

Функция `update(editor)` обновляет подсветку и отображение команд в редакторе.

Вместо последовательностей невидимых символов пользователь может видеть понятные названия операций, например:

```text
push 5
push 3
add
printn
end
```

При наведении на описание команды можно узнать, что она делает.

### Дизассемблирование

Функция `disassemble(doc)` преобразует исходный код в текстовое представление с названиями команд и их аргументами.

Результат открывается в отдельной вкладке рядом с исходным файлом. Если при разборе встречается ошибка, она выводится в виде комментария.

## 4. Инструкция по проверке и запуску

### Запуск расширения

1. Склонируйте репозиторий `https://github.com/EliasBlind/WhiteSee`.
2. Убедитесь, что в проекте присутствуют файлы `extension.js` и `package.json`.
3. Нажмите `F5`, чтобы запустить расширение в режиме разработки.
4. В открывшемся окне Extension Development Host откройте файл, которому назначен язык `whitespace`.
5. Вставьте или откройте исходный код программы на Whitespace.
6. Проверьте, что пробелы и табуляции выделяются разными цветами, а переводы строк обозначаются символом `↵`.
7. Убедитесь, что рядом с исходным кодом отображаются мнемоники команд.

### Проверка дополнительных функций

1. Откройте палитру команд сочетанием `Ctrl+Shift+P`.
2. Найдите команду переключения мнемоник и проверьте, что их отображение можно включать и отключать.
3. Выполните команду `whitespaceLang.disassemble`.
4. Убедитесь, что рядом с исходным файлом открывается новая вкладка с текстовым представлением программы.
5. Проверьте работу расширения на некорректных инструкциях и убедитесь, что ошибки выделяются красным цветом.

## 5. Структура репозитория

```text
whitespace-language-support/
├── extension.js       # Основной код плагина
├── package.json       # Настройки и команды расширения
└── README.md          # Описание проекта и инструкция
```

- `extension.js` — содержит список команд, разбор исходного кода, подсветку, отображение мнемоник и дизассемблирование.
- `package.json` — содержит информацию о расширении, идентификатор языка, настройки и зарегистрированные команды.
- `README.md` — описывает назначение проекта, его возможности и порядок проверки.
